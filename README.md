# SubletMatching

Helps Rutgers students sublet to other Rutgers students through verifiable means: sign-up is gated to Rutgers email addresses, so every listing comes from a verified student.

Active development has moved to [wymwill/RUOffCampus](https://github.com/wymwill/RUOffCampus). The live app is at https://sublet-matching.vercel.app
